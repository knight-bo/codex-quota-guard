# Установка и использование

Codex Quota Guard предоставляет рекомендательные проверки квоты. Требуются Python 3.10+, POSIX (Linux/macOS) и официальный Codex CLI с уже выполненной аутентификацией и аккаунтом, соответствующим условиям использования. Во время работы используется только стандартная библиотека Python. Исполняемый файл должен находиться в доверенном PATH.

## Установка

```sh
codex plugin marketplace add knight-bo/codex-quota-guard
```

Перезапустите настольное приложение, выберите Codex Quota Guard Local, установите и включите плагин. Публикация на GitHub не означает одобрение для публичного каталога плагинов. Установка не запускает мониторинг и не создаёт автозапуск.

## Проверка и мониторинг

Примеры запросов: «Покажи остаток квоты Codex», «Запусти мониторинг: резерв 10%, буфер 2 процентных пункта, проверка каждые 30 секунд», «Останови мониторинг квоты». Разовый запрос не запускает постоянный мониторинг.

Выполняйте команды из корня плагина. Замените STATE абсолютным путём к одному и тому же приватному каталогу состояния вне репозитория и кеша плагинов. Каталог должен принадлежать текущему пользователю, иметь права 0700 и находиться внутри доверенного доступного для записи родительского каталога.

```sh
python3 scripts/quota_guard.py read --bucket codex --state-dir STATE --format text --locale ru
python3 scripts/quota_guard.py start --bucket codex --reserve 10 --buffer 2 --interval 30 --state-dir STATE --format text --locale ru
```

Мониторинг запускается только по явному запросу. start работает на переднем плане, не как фоновая служба; следите за его сеансом. Для остановки выполните в другом терминале:

```sh
python3 scripts/quota_guard.py stop --state-dir STATE --format text --locale ru
```

Используйте тот же STATE и убедитесь в исходном сеансе, что процесс завершился. Запрос остановки сам по себе этого не подтверждает. Также поддерживается Ctrl-C.

## Ограничения

При остатке 12% или меньше в любом применимом окне рекомендательная проверка запрещает новую работу. Это не гарантирует сохранение ровно 10%: другие клиенты продолжают расходовать квоту. Проверяйте каждое окно, время измерения и актуальность. Устаревшие данные не являются текущим остатком; после времени сброса требуется новое измерение. Категория codex задаётся явно и не является универсальным соответствием для всех моделей.

По умолчанию доступны только чтение и предупреждения. Любое управляемое прерывание требует явного разрешения для точной пары thread/turn, принадлежащей оркестратору и доступной через текущий app-server. Произвольные облачные задачи не контролируются. Статус контрольной точки — unconfirmed; подтверждение прерывания не подтверждает завершение задачи или сохранение контрольной точки.

При ошибках используйте обычные процедуры одобрения и входа. Не обходите ограничения изменением прав, аутентификации или CODEX_HOME. Не читайте напрямую файлы учётных данных и журналы сеансов.
