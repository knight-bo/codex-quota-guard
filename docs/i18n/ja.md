# インストールと使い方

Codex Quota Guard は、利用枠の照会と参考情報としての監視を提供します。Python 3.10 以上、POSIX 環境（Linux/macOS）、インストール済みの公式 Codex CLI が必要です。利用条件を満たすアカウントで、通常の認証を完了しておいてください。実行時の依存関係は Python 標準ライブラリのみです。信頼できる PATH 上の公式実行ファイルを使用します。

## インストール

```sh
codex plugin marketplace add knight-bo/codex-quota-guard
```

デスクトップアプリを再起動し、Codex Quota Guard Local を選んでインストールし、有効にします。GitHub での公開は、公開プラグインディレクトリの承認を意味しません。インストールだけでは監視も自動起動も設定されません。

## 照会・開始・停止

自然言語では、「Codex の利用枠の残量を確認して」「10% を確保する目安で、バッファを 2 ポイント、間隔を 30 秒にして監視を開始して」「利用枠の監視を停止して」と依頼できます。一度だけの照会で継続監視が始まることはありません。

以下はプラグインのルートで実行します。STATE は、リポジトリとプラグインキャッシュの外にある同じ非公開の状態ディレクトリの絶対パスに置き換えてください。現在のユーザーが所有し、権限は 0700、親ディレクトリは信頼できて書き込み可能である必要があります。

```sh
python3 scripts/quota_guard.py read --bucket codex --state-dir STATE --format text --locale ja
python3 scripts/quota_guard.py start --bucket codex --reserve 10 --buffer 2 --interval 30 --state-dir STATE --format text --locale ja
```

監視は明示的な依頼でのみ開始します。start はフォアグラウンドで動作し、常駐サービスにはなりません。そのセッションを監督してください。別の端末で同じ STATE を指定して停止します。

```sh
python3 scripts/quota_guard.py stop --state-dir STATE --format text --locale ja
```

元のセッションでプロセスの終了を確認してください。停止要求だけでは終了の証明になりません。Ctrl-C でも停止できます。

## 判定と制限

この設定では、適用されるいずれかの期間の残量が 12% 以下になると、参考判定で新しい作業を許可しません。10% の確保を厳密に保証する仕組みではなく、他のクライアントも利用枠を消費できます。各期間、観測日時、有効性を確認してください。キャッシュや期限切れの値は現在の残量とは限りません。リセット時刻を過ぎても再取得が必要です。codex は明示的に選ぶ区分であり、すべてのモデルに共通ではありません。

既定では読み取りと警告のみです。管理対象の中断には明示的な許可が必要です。対象は、オーケストレーターが所有し、現在の app-server からアクセスできる正確な thread/turn の組に限定されます。任意のクラウドタスクは制御できません。チェックポイントは unconfirmed のままで、中断要求の受理もタスク完了や保存成功を証明しません。接続できない場合は通常の承認・ログイン手順を使用してください。権限、認証、CODEX_HOME の変更による制限回避や、認証情報ファイル・セッションログの直接読み取りは行わないでください。
