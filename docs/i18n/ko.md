# 설치 및 사용 안내

Codex Quota Guard는 사용 한도를 조회하고 참고용으로 모니터링합니다. Python 3.10 이상, POSIX 환경(Linux/macOS), 설치된 공식 Codex CLI가 필요합니다. 이용 조건에 맞는 계정으로 일반 인증 절차를 완료해야 합니다. 실행 시에는 Python 표준 라이브러리만 사용합니다. 신뢰할 수 있는 PATH에 있는 공식 실행 파일을 사용하세요.

## 설치

```sh
codex plugin marketplace add knight-bo/codex-quota-guard
```

데스크톱 앱을 다시 시작하고 Codex Quota Guard Local을 선택해 설치한 다음 활성화하세요. GitHub 공개는 공개 플러그인 디렉터리의 승인을 의미하지 않습니다. 설치만으로 모니터링이나 자동 시작이 설정되지는 않습니다.

## 조회, 시작, 중지

자연어로 “Codex 잔여 한도를 확인해 줘”, “예비량 10%, 여유분 2%포인트로 30초마다 한도 모니터링을 시작해 줘”, “한도 모니터링을 중지해 줘”라고 요청할 수 있습니다. 일회성 조회는 지속적인 모니터링을 시작하지 않습니다.

아래 명령은 플러그인 루트에서 실행하세요. STATE를 동일한 비공개 상태 디렉터리의 절대 경로로 바꾸세요. 이 디렉터리는 저장소와 플러그인 캐시 밖에 있어야 하며, 현재 사용자 소유이고 권한은 0700이어야 합니다. 상위 디렉터리도 신뢰할 수 있고 쓰기 가능해야 합니다.

```sh
python3 scripts/quota_guard.py read --bucket codex --state-dir STATE --format text --locale ko
python3 scripts/quota_guard.py start --bucket codex --reserve 10 --buffer 2 --interval 30 --state-dir STATE --format text --locale ko
```

모니터링은 명시적으로 요청한 경우에만 시작합니다. start는 포그라운드에서 실행되며 백그라운드 서비스가 아닙니다. 해당 세션을 유지하고 프로세스 상태를 확인하세요. 다른 터미널에서 같은 STATE를 사용해 중지를 요청합니다.

```sh
python3 scripts/quota_guard.py stop --state-dir STATE --format text --locale ko
```

원래 세션에서 프로세스가 실제로 종료되었는지 확인하세요. 중지 요청 자체는 종료를 증명하지 않습니다. 포그라운드에서 Ctrl-C로 중지할 수도 있습니다.

## 결과 해석 및 제한

이 설정은 적용되는 기간 중 하나라도 잔여량이 12% 이하가 되면 참고용 검사에서 새 작업을 허용하지 않습니다. 정확히 10%를 남긴다는 보장은 아닙니다. 다른 클라이언트가 한도를 계속 사용할 수 있습니다. 각 기간의 잔여량, 관측 시각, 유효 여부를 따로 확인하세요. 캐시되거나 만료된 값은 현재 잔여량으로 간주할 수 없습니다. 초기화 시각이 지나도 새 조회가 필요합니다. codex는 명시적으로 선택한 한도 구분이며 모든 모델에 공통으로 적용되는 것은 아닙니다.

기본 동작은 읽기와 알림뿐입니다. 관리 대상 작업을 중단하려면 명시적 승인이 필요하며, 대상은 오케스트레이터가 소유하고 현재 app-server에서 접근할 수 있는 정확한 thread/turn 쌍이어야 합니다. 임의의 클라우드 작업은 제어할 수 없습니다. 체크포인트 상태는 unconfirmed이며, 중단 요청 수락도 작업 완료나 체크포인트 저장 성공을 증명하지 않습니다.

접근에 실패하면 일반 승인 또는 로그인 절차를 이용하세요. 권한, 인증 설정, CODEX_HOME을 변경해 제한을 우회하지 마세요. 자격 증명 파일이나 세션 로그를 직접 읽어서 한도를 확인하지 마세요.
